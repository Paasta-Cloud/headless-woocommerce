# خانه‌چین: نمونهٔ فروشگاه فارسی Headless WooCommerce

یک نمونهٔ مستقل و قابل‌تغییر از فروشگاه فارسی RTL با Next.js و WooCommerce Store API. این پروژه وابسته به کد داخلی پاستا نیست. صفحهٔ محصول، سبد، حساب و صورت‌حساب دارد. ثبت سفارش فقط وقتی روش «پرداخت در محل» و ارسال در ووکامرس آماده باشند فعال می‌شود؛ درگاه آنلاین متصل نیست.

دموی عمومی: [headless-woocommerce-demo.neda1.paasta.app](https://headless-woocommerce-demo.neda1.paasta.app). شش کالای نمایشی این دمو از یک نصب واقعی ووکامرس روی پاستا دریافت می‌شوند. قیمت‌ها در ووکامرس بر حسب ریال تنظیم شده‌اند؛ خرید و پرداخت واقعی در این نمونه فعال نیست.

## راه‌اندازی

```bash
git clone https://github.com/Paasta-Cloud/headless-woocommerce.git
cd headless-woocommerce
npm install
npm run dev
```

فایل `.env` فقط مقدار غیرمحرمانهٔ `WOOCOMMERCE_URL=demo` دارد تا استقرار Git روی پاستا در حالت نمایشی کار کند. نام و قیمت‌های این حالت ساختگی‌اند. برای دریافت محصولات واقعی، `.env.example` را به `.env.local` کپی کنید و `WOOCOMMERCE_URL` را به نشانی HTTPS سایت وردپرس خود تنظیم کنید؛ در پاستا همین متغیر را در تنظیمات سرویس تغییر دهید. رمز و کلید را هرگز در `.env` عمومی ثبت نکنید. ویترین برای خواندن Store API عمومی به کلید مدیریتی نیاز ندارد.

برای استقرار روی پاستا، بعد از تنظیم نشانی ووکامرس در متغیر محیطی پروژه، از مسیر Git یا CLI استفاده کنید. ساخت پروژه و سرویس ممکن است هزینه داشته باشد؛ پلن و مبلغ را پیش از تأیید بررسی کنید. دستورهای پایه:

```bash
npm test
npm run build
paasta deploy --git https://github.com/Paasta-Cloud/headless-woocommerce.git --name my-store
```

## وضعیت قابلیت‌ها

- کاتالوگ، جست‌وجوی محلی و فیلتر دسته‌بندی کار می‌کنند. بدون تنظیم ووکامرس، سبد نمایشی و دادهٔ ساختگی نمایش داده می‌شود.
- در حالت اتصال، فهرست محصولات، تصویر، دسته‌بندی و قیمت از `/wp-json/wc/store/v1/products` دریافت می‌شود.
- هر کالا صفحهٔ مستقل دارد. در حالت اتصال، افزودن و تغییر تعداد کالا از Store API ووکامرس انجام می‌شود. Cart Token فقط در کوکی HttpOnly فرانت‌اند نگهداری می‌شود و سبد پس از بارگذاری دوباره بازیابی می‌شود. کالاهای متغیر و ناموجود در این نسخه قابل افزودن نیستند.
- حساب کاربری از مسیر امن `/my-account/` خود وردپرس باز می‌شود؛ فرانت‌اند گذرواژه را دریافت یا نگهداری نمی‌کند. ورود یکپارچهٔ داخل فرانت‌اند هنوز ارائه نمی‌شود.
- صورت‌حساب واقعی، نشانی و تماس را اعتبارسنجی می‌کند، مبلغ را دوباره از ووکامرس می‌خواند و فقط در صورت فعال‌بودن روش `cod` و ارسال انتخاب‌شده سفارش ثبت می‌کند. در پاسخ نامشخص، کاربر باید پیش از تلاش مجدد سفارش‌های حساب یا ایمیل را بررسی کند.
- سوئیچ `STORE_CHECKOUT_ENABLED` پیش‌فرض خاموش است. پس از تعیین نشانی تحویل حضوری، پیکربندی روش دریافت در ووکامرس و آزمون سفارش، آن را در متغیرهای سرویس روی `true` بگذارید.
- واحد پول از پاسخ ووکامرس خوانده می‌شود و تبدیل پنهانی ریال به تومان انجام نمی‌شود؛ تنظیم واحد پول فروشگاه را پیش از عرضه بررسی کنید.
- پرداخت آنلاین وجود ندارد. فعال‌سازی پرداخت در محل و روش ارسال باید با محدودهٔ واقعی خدمت و هزینهٔ صحیح در ووکامرس انجام شود؛ تا آن زمان دکمهٔ ثبت سفارش بسته می‌ماند. این شش کالا ساختگی هستند و برای فروش عمومی واقعی مناسب نیستند.
- مسیر `/api/health` برای بررسی زنده‌بودن فرانت‌اند پاسخ ۲۰۴ می‌دهد؛ سلامت ووکامرس را جداگانه بررسی کنید.
- قبل از فروش واقعی، دامنه و TLS، تصاویر و مجوزشان، SEO محصولات، راهکار کش/تازه‌سازی، مالیات و هزینهٔ حمل را با فروشگاه خودتان آزمون کنید.

فونت «یکان‌بخ» در CSS اولویت دارد، اما به‌دلیل نیاز به بررسی مجوز بازنشر، فایل فونت در این نمونه بسته‌بندی نشده است. اگر مجوز استفاده دارید، فایل فونت را در `public/fonts/yekan-bakh.woff2` بگذارید و `@font-face` مناسب را به `app/style.css` اضافه کنید. در غیر این صورت فونت جایگزین سیستم نمایش داده می‌شود.

کد نمونه تحت مجوز MIT است. این نمونه از برند، تصاویر و چیدمان دیجی‌کالا کپی نمی‌کند و هویت مستقل «خانه‌چین» دارد. مجوز هر دارایی تصویری/فونت که خودتان اضافه می‌کنید باید بررسی شود.
